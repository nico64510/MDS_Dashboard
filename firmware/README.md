# Fichiers de mise à jour

Un fichier par version : `mds_dashboard_vX.Y.Z.bin`. Prenez toujours le numéro le plus élevé (voir [`../CHANGELOG.md`](../CHANGELOG.md)). Les versions précédentes restent disponibles si vous devez revenir en arrière.

Procédure de mise à jour : voir le [README](../README.md#mettre-à-jour-lécran).

> Ces fichiers fonctionnent uniquement sur les écrans MDS Dashboard préparés par MDS Workshop. Les écrans sont livrés avec le logiciel déjà installé ; les mises à jour se font ensuite depuis la page de réglages, sans câble.
